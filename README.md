# API Document
## Endpoints
List all the available endpoints provided by the API along with a brief description of each.


### /api/info/set

Method: POST

Description: Save User Information

Request Body:
``` 
{
  "gender": "",
  "type_run": "",
  "birthdate": "",
  "bibnumber": "",
  "phonenumber": "",
  "idcard": "",
  "healthproblems": "",
  "emergencyphone": "",
  "emergencontact": "",
  "relationship": "",
  "bloodtype": "",
  "email": "",
  "bib_number": ""
}
``` 
Response Body:
``` 
{
  "message": ""
}
```
